# How to use this kit

This kit turns the EPPC26 session **"Rethinking Governance Models for AI Agents"** into something you can act on Monday morning. Each part maps to a section of the talk, but is written to stand on its own — jump straight to the part you need.

Read it in order the first time. After that, treat it as a reference: the tables and checklists are designed to be copied into your own governance documentation.

> [!IMPORTANT]
> Agent 365, Copilot Studio Kit, Defender, and Purview are your **control planes**. They enforce what you decide — they are not a substitute for a governance model. This kit helps you build that model first.
