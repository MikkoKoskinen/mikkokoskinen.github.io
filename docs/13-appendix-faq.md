# Appendix 3 — Frequently asked questions

**Is the Copilot Studio Kit free?**
Yes — it's open source on GitHub, maintained by Power CAT.

**Does it require premium licenses?**
The Kit itself runs in a Dataverse environment, so a Power Apps or Power Platform license is needed. Agent Insights Hub requires an Azure subscription for Application Insights.

**Is Compliance Hub automatic after install?**
No — you configure the thresholds and enforcement actions first, then it runs continuously.
