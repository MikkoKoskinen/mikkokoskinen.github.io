# Part J — Governance roadmap

Three phases, in order. Don't skip ahead — each phase is the foundation for the next.

### Phase 1 · Foundations
- Define maker scope & pilot group
- Create the CS Authors Entra ID group
- Configure the PPAC Copilot Authoring Group
- Set up your licensing model

### Phase 2 · Environments
- Create the Sandbox Environment Group + Routing
- Configure Environment Group Rules (sharing, onboarding, ACP)
- Create Shared Dev & Prod environments
- Set up security groups + Entra Group Teams

### Phase 3 · Policies & ALM
- Configure DLP per Environment Group
- Set Advanced Connector Policies (ACP)
- Define the production deployment approval process
- Enable ALM pipelines Dev → Prod

> [!TIP]
> Governance isn't a blocker to innovation — it's what makes sustainable innovation possible. Organizations that get this right early move faster later, because they aren't cleaning up ungoverned AI debt.
